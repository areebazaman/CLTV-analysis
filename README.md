# CLTV-analysis
CLTV Analysis in Python
Overview
This project analyzes Customer Lifetime Value (CLTV) using a dataset of 800 customers. It includes CLTV calculation, customer segmentation, and visualizations to understand channel performance and customer value.

Tools
Python, Pandas, Matplotlib, Seaborn

Run the Project

pip install pandas matplotlib seaborn

python cltv_analysis.py
